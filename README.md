# Noban

**Noban** é uma plataforma de gerenciamento de projetos baseada no conceito de **Kanban**, desenvolvida com foco em organização de tarefas, controle de projetos e gerenciamento de colaboradores.

O projeto também serve como estudo prático de desenvolvimento de aplicações web, explorando autenticação, autorização, persistência de dados, arquitetura de APIs e integração entre frontend e backend.

## Tecnologias

### Backend

- Java 21
- Spring Boot
- Spring Security
- JWT
- Spring Data JPA / Hibernate
- PostgreSQL
- Maven

### Frontend

- Angular
- JavaScript

### Infraestrutura

- Docker
- Docker Compose
- PostgreSQL
